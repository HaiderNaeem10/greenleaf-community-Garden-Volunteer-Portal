# GreenLeaf Community Garden Volunteer Portal

A React-based landing page for a community garden volunteer portal.

## Features
- GreenLeaf branding and welcome message
- Home, Events, and Volunteer navigation links
- Community garden information
- Volunteer section
- Responsive design for mobile screens

## Technologies Used
- React.js
- HTML
- CSS
- JavaScript

## How to Run
1. Install Node.js.
2. Clone this repository.
3. Run npm install.
4. Run npm start.
5. Open http://localhost:3000 in your browser.
